## Generating Diagrams

```powershell
# Generate all graphs
.\scripts\sweep\graph-generator.ps1 -InputType all

# Generate specific graph types
.\scripts\sweep\graph-generator.ps1 -InputType cargo    # Cargo dependencies
.\scripts\sweep\graph-generator.ps1 -InputType modules  # Module structure
.\scripts\sweep\graph-generator.ps1 -InputType docs     # Doc coverage
.\scripts\sweep\graph-generator.ps1 -InputType symbols  # Symbol relationships
```

## Diagram Standards

- Use Mermaid syntax for version-controlled diagrams
- Save as `.mmd` files for raw Mermaid
- Export to `.png` or `.svg` for static documentation
- Follow the naming convention: `{domain}-{type}.mmd`
