# BMAD Templates

Use these templates to keep BMAD outputs consistent across runs and providers. Each file is intentionally lightweight so it can be pre-filled by agents and edited by humans when needed.

- `analysis.md` — captures objectives, constraints, stakeholders, and initial risks.
- `architecture.md` — captures system context, options, and decisions.
- `backlog.md` — captures the cross-role backlog slices (analysis, architecture, delivery).
