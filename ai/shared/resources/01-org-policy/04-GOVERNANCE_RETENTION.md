# Retention and Archival Policy

| Status | Version | FR |
|--------|---------|-----|
| **Active** | 1.0.0 | FR-001 |

## Core Principle

**Never delete. Always archive.**

All configuration, tool, and data files that would be removed MUST instead be archived with a README note explaining the archival reason.

---

## Retention Periods

| Asset Type | Retention | Archive Path | Compression |
|------------|-----------|--------------|-------------|
| Tool archives | 7 days | `${NOA_ROOT}/opt/archive/` | 7z LZMA2 |
| Config archives | 30 days | `${NOA_ROOT}/opt/archive/config/` | 7z LZMA2 |
| CAS blobs (unreferenced) | 30 days | `${NOA_ROOT}/cas/gc/` | None (already content-addressed) |
| Execution memory | 90 days | `${NOA_ROOT}/data/archives/execution-memory/` | 7z LZMA2 |
| Logs | 7 days rolling | `${NOA_ROOT}/logs/archive/` | gzip |
| Build artifacts | 3 days | `${NOA_ROOT}/tmp/builds/` | None (can regenerate) |
| Temp files | 1 day | `${NOA_ROOT}/tmp/` | None (can delete) |

---

## Archive Requirements

### R1: README Note

Every archive MUST include a `README.md` (or append to existing) with:

```markdown
## Archived: [filename]
- **Date**: YYYY-MM-DD
- **Reason**: [why archived]
- **Original version**: [version if applicable]
- **Superseded by**: [replacement if applicable]
- **Restoration**: [how to restore if needed]
```

### R2: Maximum Compression

Use 7z with LZMA2 for optimal compression:

```bash
# Windows (PowerShell)
7z a -t7z -m0=lzma2 -mx=9 archive.7z file-to-archive

# Unix
7z a -t7z -m0=lzma2 -mx=9 archive.7z file-to-archive
```

Compression levels:
- `-mx=9` - Ultra (default for archives)
- `-mx=7` - Maximum (for faster archival)
- `-mx=5` - Normal (for very large files)

### R3: Naming Convention

```
{original-name}.{version}.{YYYYMMDD-HHMMSS}.7z
```

Examples:
- `tools.json.2.0.0.20251219-014100.7z`
- `bootstrap-tools.json.2.1.0.20251219-014100.7z`
- `execution-memory.db.20251219-000000.7z`

### R4: Upgrade Before Archive

When upgrading tools or configs:

1. Archive current version FIRST
2. Create README note
3. Apply upgrade
4. Update state/version tracking
5. Verify upgrade success

```
${NOA_ROOT}/
├── opt/

│       ├── config/        # Config file archives
│       │   └── README.md  # Archive manifest
│       ├── tools/         # Tool binary archives
│       └── providers/     # Provider archives
├── data/
│   └── archives/          # Data archives
│       └── execution-memory/
├── logs/
│   └── archive/           # Log archives
└── cas/
    └── gc/                # GC'd CAS objects (before final deletion)
```

## Garbage Collection

### CAS Objects

Unreferenced CAS objects enter a grace period before archival:

```
cas.retention_days = 30
cas.gc_schedule = "0 2 * * 0"  # Weekly at 2 AM Sunday
```

GC process:
1. Mark objects not referenced by any ref or tag
2. Move to `${NOA_ROOT}/cas/gc/` with timestamp
3. After retention period, compress and archive
4. Never permanently delete

### Logs

Rolling log retention:

```yaml
logs:
  max_age_days: 7
  archive_on_rotate: true
  compression: gzip
  archive_path: "${NOA_ROOT}/logs/archive/"
```

## Exceptions

| Exception | Approval | Rationale |
|-----------|----------|-----------|
| `${NOA_ROOT}/tmp/` files > 1 day | None | Truly temporary, regenerable |
| `node_modules/` | None | Regenerated by pnpm install |
| Build outputs in `target/`, `dist/` | None | Regenerated by build |
| `.git/objects/` loose objects | None | Git handles its own GC |

## Implementation

### Archive Helper Script

```javascript
// scripts/archive.js
import { execSync } from 'child_process';
import { appendFileSync, existsSync, mkdirSync } from 'fs';
import { basename, dirname, join } from 'path';

export function archive(filePath, reason, supersededBy = null) {
  const NOA_ROOT = process.env.NOA_ROOT;
  const archiveDir = join(NOA_ROOT, 'opt/archive', dirname(filePath).split('/').pop());
  
  if (!existsSync(archiveDir)) {
    mkdirSync(archiveDir, { recursive: true });
  }
  
  const timestamp = new Date().toISOString().replace(/[:.]/g, '-').slice(0, 19);
  const name = basename(filePath);
  const archiveName = `${name}.${timestamp}.7z`;
  
  // Compress
  execSync(`7z a -t7z -m0=lzma2 -mx=9 "${join(archiveDir, archiveName)}" "${filePath}"`);
  
  // Update README
  const readmePath = join(archiveDir, 'README.md');
  const note = `
## Archived: ${name}
- **Date**: ${new Date().toISOString().slice(0, 10)}
- **Reason**: ${reason}
${supersededBy ? `- **Superseded by**: ${supersededBy}` : ''}
- **Archive**: ${archiveName}

`;
  appendFileSync(readmePath, note);
  
  return join(archiveDir, archiveName);
}
```

## Monitoring

Archive disk usage should be monitored:

```bash
# Check archive sizes
du -sh ${NOA_ROOT}/opt/archive/*
du -sh ${NOA_ROOT}/data/archives/*
du -sh ${NOA_ROOT}/logs/archive/
```

Alert if:
- Archive directory > 10 GB
- Single archive file > 1 GB
- Archive growth > 1 GB/week
